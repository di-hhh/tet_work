## 1. 执行提醒

> **重要提醒（需要额外思考）：** 本执行顺序是候选的最小风险路径，不代表所有实验必须机械运行。每次进入新关卡前，应复核上一关的结果是否仍支持当前研究问题。模型调参、备选路线切换和成功阈值必须有记录，不应在看到 test 指标后临时改变。

## 2. 实验准入关卡

### Gate A：工程准入

要求：

- Python conda 环境锁定。
- 相关单元测试通过。
- `torch-scatter` 或兼容路径明确。
- 两个仓库工作树和 commit 已记录。

失败处理：停止训练，修复环境或测试。

### Gate B：数据准入

要求：

- 当前路径可直接加载真实数据。
- retained split 数量符合 frozen summary。
- geometry overlap 为 0。
- 所有路径、tetra、indicator、stage field 通过审计。
- manifest/quality hash 已保存。

失败处理：停止训练，不允许用手工复制到旧 `D:\SITP` 的方式掩盖可移植性缺陷。

### Gate C：配置准入

要求：

- M0/M1/M2/M3/M4 配置可组合。
- 每个配置打印实际信息流。
- M2 的 final=expert 退化测试通过。
- M4 能加载对应 M1 checkpoint。

### Gate D：评估准入

要求：

- reference-self PDE error 接近 0。
- scalar 与 elasticity evaluator 均通过 fixture。
- 逐样本 CSV schema 固定。
- 主指标和统计规则冻结。

## 3. Seed-0 Pilot

### 3.1 运行对象

按依赖运行：

```text
M0 原始 AMBER
M1 weighted
M2 feature-only
M4 stage-field correction（从 M1 初始化）
M3 indicator correction
```

### 3.2 Pilot 只回答运行正确性

检查：

- loss 是否有限。
- train/val 是否完整结束。
- weight loaded/fallback 状态。
- physics feature source 是否正确。
- graph/label shape。
- mesh generation success。
- gate/correction 是否全零、NaN 或饱和。
- checkpoint、config 和 CSV 是否落盘。
- PDE evaluator 能否处理预测 mesh。

Pilot 不用于最终优劣结论。

### 3.3 Pilot 失败处理

- 数据为空：回到 Gate B。
- shape mismatch：增加最小回归测试再修复。
- mesh 大量失败：先核对 sizing transform、budget、inference steps，不立即调模型。
- gate 全零：核对 feature availability、warmup、init 和正则。
- PDE solve 失败：核对 condition selector 和预测 mesh quality。

## 4. 正式实验顺序

### 4.1 主实验

1. 运行 R0/R1 静态参照。
2. 运行 M0、M1 的固定多个 seeds。
3. 使用每个 seed 对应 M1 checkpoint 运行 M4。
4. 运行 M2 控制组；其结果若影响 gate 贡献解释，则补齐相同 seed。
5. 运行 M3 作为 source 消融。

### 4.2 同步离线评估

每个 checkpoint 完成后立即：

- 导出 test meshes/predictions。
- 运行 PDE evaluator。
- 检查预算和失败率。
- 生成逐样本 CSV。

不要等所有训练结束后才发现 evaluator 或数据协议错误。

### 4.3 诊断实验

仅在主结果暴露问题后运行：

- PDE-specific models。
- warmup/regularization 小消融。
- fixed gate/no gate。
- missing feature robustness。
- ABC external test。

## 6. 实验产物规范

每个 run 独立目录，禁止多个方法覆盖同一位置。

```text
<method>/<seed>/
├── resolved_config.yaml
├── environment.txt
├── code_version.json
├── dataset_version.json
├── checkpoints/
├── logs/
├── predictions/
├── generated_meshes/
├── per_sample_metrics.csv
└── aggregate_metrics.json
```

每次运行必须记录：

- method ID。
- seed。
- 两仓库 commit 和 dirty 状态。
- manifest/quality hash。
- checkpoint 选择依据。
- 硬件。
- 启动命令。
- 开始/结束时间使用北京时间。

## 7. 自动检查

### 7.1 训练前

- 环境 import。
- Git 状态。
- dataset audit。
- config compose。
- 单 batch forward/loss。

### 7.2 训练中

- NaN/Inf。
- weight/feature loaded。
- loss term 量级。
- gate/correction 分布。
- validation primary metric。
- checkpoint 写入。

### 7.3 评估后

- 样本数与 frozen test 一致。
- 失败样本保留行。
- element budget 分布。
- 每个 PDE family 指标非空。
- aggregate 可由 per-sample CSV 重算。
- 多 seed 使用相同协议。

## 8. 结果判定和止损

### 8.1 M1 不优于 M0

检查：

- indicator/weight 分布。
- weights 是否实际进入 loss。
- teacher importance 与 PDE error 的一致性。
- weighted 改善是否以全域退化为代价。

若多 seed 仍无改善，停止 correction 主实验扩张，先判断 physics weighting 假设是否成立。

### 8.2 M4 不优于 M1

检查：

- M4 是否看到正确 stage field。
- expert-only 与 final。
- gate saturation。
- correction magnitude。
- warmup/regularization。

只进行一次或少量有诊断依据的修正；仍无改善则保留 M1，停止堆叠模型。

### 8.3 M2 与 M4 相当

结论倾向：stage-field input 有效，gated residual 没有独立增益。

切换备选：使用更简单 feature-only 模型作为主技术路线；gate 作为分析对象。

### 8.4 Sizing 改善但 PDE 不改善

- 不声称物理性能提升。
- 检查 indicator 语义和 reference evaluator。
- 将结果限定为 critical-region teacher imitation。

### 8.5 PDE 改善但预算增加

- 绘制 error-vs-elements。
- 在匹配预算区间重比较。
- 不把额外网格成本当作模型收益。

> **额外思考提醒：** 上述切换规则是候选决策框架。正式采用前应结合实际方差、失败类型和工程意义判断，不能用单 seed 或单指标触发重大路线变化。

## 9. 风险与应对

| 风险 | 识别信号 | 应对 |
|---|---|---|
| 绝对路径失效 | split 全空 | 路径协议修复与审计 |
| 环境不一致 | import/type/DLL error | 固定 Python 3.11 和依赖 |
| 数据泄漏 | geometry overlap | geometry-level split assert |
| 标签/物理特征泄漏 | 输入接近 target sizing | 审计 field 生成语义 |
| Condition 不可辨识 | geometry-only 多 target | feature-only/PDE-specific 控制 |
| Joint 负迁移 | 分 PDE 明显不一致 | PDE-specific 诊断 |
| Gate 退化 | 全零或全一 | 检查初始化、正则、输入 |
| Mesh failure | solver/mesher success 下降 | 先查 transform 与 budget |
| Reference 不可靠 | teacher 自身误差异常 | 强化 test reference |
| 结果不可追溯 | 缺 config/hash/CSV | 强制产物 schema |
| ABC 不稳定 | ingestion/quality pass 低 | 保留 Mold 主线，停止扩展 |
