# 实验指标与统计规则

## 文档信息

- **修改内容**：独立整理真实 PDE、sizing imitation、预算、网格质量、效率、机制诊断和统计规则。
- **文档概述**：本文统一规定实验输出哪些指标、每个指标回答什么问题、如何聚合以及如何判断优劣。指标分为五层：真实 PDE 性能、teacher sizing imitation、高重要区域分配、预算与网格有效性、效率与机制诊断。统计上以 geometry 为基本独立单位，避免同一 geometry 的多个 conditions 被当作独立样本；主方法使用多个固定 seed，并建议使用 paired geometry-level bootstrap。本文同时提供指标实现不完整时的备选层级，但明确 sizing error 不能替代 PDE error 支撑物理收益。

## 1. 指标设计提醒

> **重要提醒（需要额外思考）：** 主指标、积分域、reference 精度和统计检验是创造性实验决策。正式冻结前应由熟悉 FEM 的研究者检查公式。尤其不能因某个指标更容易得到好结果就将其设为主指标；主指标应在查看 test 结果前固定，并与方法声称解决的问题直接对应。

## 2. 一级指标：真实 PDE 性能

### 2.1 公共 probe 上的相对 L2

候选定义：

```text
E_L2 = sqrt(
  sum_q omega_q * ||u_pred(x_q) - u_ref(x_q)||^2
  / (sum_q omega_q * ||u_ref(x_q)||^2 + eps)
)
```

其中 `x_q` 为公共 probe/reference quadrature points，`omega_q` 为体积权重。

### 2.2 Scalar elliptic

建议报告：

- `scalar_relative_solution_l2`。
- `scalar_relative_energy_error` 或 `relative_h1_seminorm_error`。
- `scalar_relative_qoi_error`。
- `scalar_solver_success`。

### 2.3 Linear elasticity

建议报告：

- `elasticity_relative_displacement_l2`。
- `elasticity_relative_energy_error`。
- `elasticity_relative_qoi_error`。
- `elasticity_solver_success`。

### 2.4 备选层级（根据 @对030408的实现报告.md，以下备选思路是否已有更强实现？以下哪些需要选择？请你向我确认）

若 energy norm 还未验证：

1. 先使用 relative solution/displacement L2。
2. 加入 condition-defined QoI error。
3. 将 energy error 标为待验证，不输出不可信数值。

若 reference 强度不足：

- 对 test 集生成更强 reference；或
- 将指标命名为 teacher-reference discrepancy，不称为 ground-truth PDE error。

## 3. 二级指标：Sizing imitation

- `projected_l2_error`。
- `projected_l2_error_reverse`。
- `projected_l2_error_symmetric`。
- `physics_weighted_projected_l2_error`。
- `weighted_size_l2`。
- 全域 unweighted size L2。

这些指标衡量预测 mesh sizing 与 teacher target 的接近程度。

## 4. 高重要区域指标

- `topk_high_importance_l2`。
- `bucket_high_size_l2`。
- `bucket_low_size_l2`。
- `bucket_high_low_ratio`。
- 可选：importance-error Spearman correlation。

推荐固定 top-k 百分比和 bucket 数，不随 test 结果调整。

解释：

- high error 下降、low 略升：可能是精度向关键区域重分配。
- high/low 都下降：整体改进。
- weighted 下降但 top-k 不降：检查权重分布是否过于平滑。

> **额外思考提醒：** high-importance 区域由 teacher indicator 定义。如果 indicator 本身与真实 PDE error 不一致，高区域指标改善未必有物理意义。应计算 indicator 与局部参考误差或 QoI sensitivity 的一致性诊断。

## 5. 预算与网格有效性

必须报告：

- `num_elements`。
- `num_vertices`。
- `budget_ratio = num_elements / desired_budget`。
- `absolute_budget_deviation`。
- `budget_success_rate`。
- `mesh_generation_success_rate`。
- invalid/inverted tetra count。
- tetra quality minimum、q05、median。
- refinement scaled/failed 状态。

比较 PDE error 时，同时给出 budget。若元素数差异较大，考虑：

- 按预算分层。
- 对 PDE error 做 error-vs-elements 曲线。
- 报告相同容差下所需 elements。

## 6. 效率指标

- GNN forward time。
- mesh generation time。
- PDE evaluation solve time。
- end-to-end inference time。
- training time/updates。
- teacher generation time作为离线参考。
- 可选 peak GPU memory。

计时应：

- 区分 warmup 与稳态。
- GPU 同步。
- 使用相同硬件和 batch 条件。
- 不把离线 stage-field 生成时间隐藏在推理成本之外；若部署时必须预先计算，应单独报告。

## 7. 机制诊断

### 7.1 Gate

- mean/std/min/max。
- high/low importance mean。
- 按 PDE family 分组。
- 与 expert error 的相关性。

### 7.2 Correction

- `abs(delta_phys)`。
- `abs(alpha * delta_phys)`。
- high/low importance correction。
- correction sign 与 target residual 一致率（可选）。

### 7.3 Expert vs final

分别计算：

- 全域 size L2。
- weighted size L2。
- top-k high error。
- PDE error（如果可以为两条预测都生成 mesh）。

关键判据：final 应优于 expert-only，不能只看 correction 非零。

## 8. 聚合与统计

### 8.1 基本单位

同一 geometry 多 conditions 相关。推荐：

1. 保留逐 sample 结果。
2. 在 geometry 内按 PDE/condition 求平均。
3. 跨 test geometries 聚合。

### 8.2 Seed

主方法建议使用固定 seeds 0、1、2。

报告：

- seed mean ± std。
- 每 seed geometry-level mean/median。
- 逐 geometry paired difference。

### 8.3 置信区间

推荐 geometry-level paired bootstrap 95% CI：每次以 geometry 为单位重采样，保留其所有 conditions。

可选 paired Wilcoxon signed-rank test；多比较时使用 Holm correction。

### 8.4 PDE 分项

分别报告 scalar 与 elasticity。Joint aggregate 只能作为补充，防止一个 PDE 的改善掩盖另一个退化。

## 9. 优劣判断

### 9.1 主判断顺序

1. Solver/mesh success 不下降。
2. 实际 budget 可比。
3. PDE 主指标降低。
4. high-importance sizing error 降低。
5. runtime/训练成本可接受。
6. 机制指标与性能增益一致。

### 9.2 候选成功标准

可在正式 test 前固定如下候选规则：

- 两类 PDE 的预指定主指标方向一致。
- geometry-level paired CI 支持改善，或效应量达到预先约定阈值。
- budget deviation 没有系统性恶化。
- mesh success rate 没有实质下降。
- M4 final 优于 M4 expert-only。

> **额外思考提醒：** 不建议机械采用任意百分比作为“成功线”。阈值应结合 baseline 方差、PDE 数值误差、实际工程意义和样本量确定，并在读取 test 结果前记录。

### 9.3 不能得出的结论

- 仅 weighted L2 下降：不能证明 PDE 更准。
- 仅 gate 在高区更大：不能证明 correction 有效。
- 仅单 seed 提升：不能证明稳定。
- 仅平均值提升：不能忽略某 PDE 或大量 geometry 退化。
- PDE error 下降但 elements 大幅增加：不能视为同预算提升。

## 10. 逐样本结果格式

每行至少包含：

```text
run_id, method, seed, checkpoint
sample_id, geometry_id, condition_id, pde_family, split
desired_budget, num_elements, budget_ratio
mesh_success, solver_success, runtime
projected_l2_error_symmetric
weighted_size_l2, topk_high_importance_l2
bucket_low_size_l2, bucket_high_size_l2
relative_solution_l2, relative_energy_error, relative_qoi_error
gate_mean, gate_high_mean, gate_low_mean
applied_correction_abs_mean
expert_only_error, final_error
code_commit, manifest_hash
```

无效值使用显式状态和 NaN，不删除整行。
