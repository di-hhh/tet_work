## 1. 创造性方案提醒

> **重要提醒（需要额外思考）：** 消融和模型修改都是创造性研究决策。本文给出的关系式只在控制变量真正成立时有效。执行前必须核对计算图、输入可见性、参数量、初始化、训练步数和 checkpoint 来源。任何新增模块都应先说明它解决的已观察失败，而不是因为“可能更强”就加入。

| ID | Weighted loss | Physics feature | Correction | 回答的问题 |

| A0 | 关闭 | 无 | 关闭 | 原始 AMBER |
| A1 | indicator-linear | 无 | 关闭 | loss weighting 的贡献 |
| A2 | indicator-linear | stage field | gate=0 | physics input 的贡献 |

关键差分：

- A1 - A0：weighted loss。

- A4 - A2：gated correction 净贡献。
- A4 - A3：stage field 相对 indicator 作为模型输入的贡献。

## 3. Gate 与 residual 消融

### 3.1 Gate=0

验证退化一致性，并作为 feature-only 控制。

### 3.2 固定 gate

候选：`alpha=1` 或固定小常数。

用途：判断学习 gate 是否必要，还是 residual head 本身足够。

风险：固定 gate 可能改变 correction 尺度，需要保持 residual 初始化和正则一致。

### 3.3 无 gate 直接 residual

```text
delta_total = delta_expert + delta_phys
```

仅在 gate 长期饱和为 1 或 gate 学习不稳定时考虑。

### 3.4 Gate 只看 physics feature

当前 gate 输入 latent；备选可让 gate 显式看到 physics scalar。

这属于模型修改，只有在 gate 与 importance 完全无关系且 correction 确实需要区域选择时考虑。

> **额外思考提醒：** gate 高重要区域更大并非必然正确。若 expert prior 已在高重要区域准确，合理 gate 可能在中等重要但 expert error 高的区域更活跃。应联合分析 importance、expert error 和 correction gain，而不是预设单调关系。

## 4. Physics source 消融

### 4.1 Indicator vs stage field

- `pipeline_indicator`：接近 teacher final error allocation，直接用于 loss。
- `s_pde_raw`：更接近 condition-dependent 中间物理场。

比较 A3/A4，判断模型输入需要 final indicator 还是更原始物理场。

### 4.2 Stage-field fusion

候选字段：

- `s_pde_raw`。
- `h_pde_only`。
- `h_after_geometry_fusion`。
- `h_after_budget_calibration`。

候选融合：单字段、加权均值。

不建议一次搜索大量组合。先根据字段语义选择 1 个主字段和 1 个有明确问题的备选。

> **额外思考提醒：** `h_after_budget_calibration` 可能与 target sizing field 过于接近，作为输入可能形成近似标签泄漏。使用前必须确认该字段在真实推理时是否可获得、生成成本是否合理，以及它是否包含 teacher target 的直接派生信息。

### 4.3 方向和归一化

当前候选：`log1p + robust_minmax`。

仅当观测到饱和、极端值或跨 PDE 尺度不一致时，比较：

- raw/clip/log1p。
- per-sample vs dataset-level normalization。

归一化统计必须仅由 train 计算；per-sample normalization 会丢失样本间绝对强度信息，需要明确取舍。

## 5. 训练策略消融

### 5.1 从 weighted checkpoint 初始化 vs 从头训练

用途：判断提升来自结构还是两阶段训练。

需要控制总更新步数或同时报告训练成本。

### 5.2 Warmup

比较：

- correction warmup 开启。
- warmup 关闭。

仅在初期 correction 爆炸或 expert prior 被破坏时运行。

### 5.3 Expert auxiliary loss

候选：默认值 vs 0。

用途：判断 expert prior 稳定性是否依赖 auxiliary supervision。

### 5.4 Correction regularization

候选：默认值 vs 0 或一个更小值。

不要做大网格搜索。依据 `abs(alpha*delta_phys)`、final-expert gain 和过拟合情况选择。

> **额外思考提醒：** 调整 `lambda_expert_aux/lambda_corr_aux/lambda_corr_reg` 会同时改变优化尺度。应先记录每个 loss term 的量级，避免只比较系数数值。

## 6. Joint/PDE-specific 诊断

### 6.1 问题

同一 geometry 有 scalar 与 elasticity 多个 targets。geometry-only 模型无法明确区分 condition。

### 6.2 诊断组

- Joint A0/A1/A4。
- Scalar-only A0/A1/A4。
- Elasticity-only A0/A1/A4。

### 6.3 解释

- PDE-specific 明显优于 joint：存在负迁移或 condition 表示不足。
- A4 joint 接近 PDE-specific：stage field 提供了有效 condition 表示。
- A0/A1 PDE-specific 提升大：不能把 joint baseline 的低性能完全归因于模型能力。

## 7. 缺失特征鲁棒性

在同一 checkpoint 上评估：

- 正常 physics feature。
- zero feature。
- `gate_zero` fallback。
- 可选：加入轻微噪声或遮挡高值区域。

目的：验证模型是否完全依赖 physics field，以及 fallback 是否安全。

噪声实验不是主性能实验，只用于机制和部署鲁棒性。

## 8. 模型备选思路（根据 @对030408的实现报告.md，以下备选思路是否已有更强实现？以下哪些需要选择？请你向我确认）

以下仅在对应触发条件成立时考虑。

### 8.1 备选一：单头 condition-aware AMBER

结构：stage field 拼到 node features，仍用原始单 head。

触发条件：A2 与 A4 相当。

优点：最简单，参数更少。

意义：说明条件特征比 residual decomposition 更重要。

### 8.2 备选二：Residual 无学习 gate

结构：expert + 固定尺度 residual。

触发条件：gate 饱和或不稳定，但 residual 有明确增益。

### 8.3 备选三：PDE-type 条件标识

增加 scalar/elasticity one-hot，仍保持一维 physics field。

触发条件：PDE-specific 明显优于 joint，stage field 不能充分区分 PDE family。

风险：需要为所有对比方法提供相同 type feature，避免信息不公平。

### 8.4 备选四：双通道 indicator + stage field

同时输入 final importance 与 raw physics field。

触发条件：A3 和 A4 在不同 PDE 各有优势，且单通道不足。

风险：需要修改输入维度和 checkpoint 迁移；可能引入标签近似泄漏。

### 8.5 备选五：PDE-specific heads

共享 encoder，scalar/elasticity 使用不同 expert/correction heads。

触发条件：joint 负迁移明确、PDE-type feature 仍不足。

风险：改动和参数增加较大，不应作为首选。

## 9. 不建议开展的扩展

- 端到端可微 FE。
- 每步训练运行 FE。
- trajectory curriculum。
- multi-step imitation 新监督。
- stage-field auxiliary multi-task loss。
- 新 GAT/UNet 主干。
- 大规模超参数/权重模式搜索。
- 未经信息可用性审计的 teacher field 输入。

这些方向可能有研究价值，但会改变当前最小增量方法的边界。

## 10. 消融选择规则

优先级：

1. A0/A1/A2/A4。
2. A3。
3. joint/PDE-specific 诊断。
4. 只针对已观察异常选择一个 gate 或训练消融。
5. 模型备选必须有触发证据后才实施。

每个消融在运行前记录：假设、唯一变化、预期能区分的解释、失败后如何处理。若不能明确回答问题，不运行。
